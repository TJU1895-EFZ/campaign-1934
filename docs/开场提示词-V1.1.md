你接手的是一个已完成 V1 的网页项目「Campaign 1934」——长征重大战役（飞夺泸定桥）第一人称模拟应用。V1 使用 Three.js + TypeScript，已通过验收（76 单元测试 + 17 e2e 测试）。

**V1.1 的核心任务：将项目从 Three.js 迁移到 Unity WebGL，实现照片级真实视觉。**

## 第一步：安装 Unity 开发环境（自行完成，约 1–2 小时）

在 Windows 11 上按顺序安装：

1. **Unity Hub**：https://unity.com/download
2. **Unity 2022.3 LTS**：通过 Hub 安装，勾选 **WebGL build support** 和 **C# support**
3. **Visual Studio 2022 Community**：工作负载选择 **"Unity 游戏开发"**
4. **Blender**：https://www.blender.org/download/（用于模型获取与修改）

Unity 安装约 15–25 GB，Blender 约 500 MB。安装完成后用 Unity 创建新项目，选择 **3D (URP) Template**，项目名 `Campaign1934`。

通过 Package Manager 安装：
- `com.unity.inputsystem`（新版输入系统）
- `com.unity.test-framework`（单元测试）
- `com.unity.addressables`（资源管理）

## 第四步：理解本次任务（V1.1 迭代）

本次任务共六组，按顺序交付：

| 组别 | 内容 | 依赖 |

## 第五步：必须遵守的硬约束

- 所有素材必须使用 **MIT 授权**。项目方已提供的素材在 `public/assets/` 目录（含参考图与影视资料），fork/clone 即可获取。
- MIT 素材库里没有现成的 1934 年中国军事模型。**获取模型和修改模型全由 AI 完成**：AI 从 Unity Asset Store 筛选 MIT 授权的通用士兵模型包下载，然后在 Blender 或 Unity 中修改服装颜色、添加红袖标、更换头盔。参考图在 `public/assets/reference/ref_model_soldier_red.jpeg` 和 `ref_model_soldier_kmt.jpeg`。
- 素材未到位就用占位实现，路径集中配置，不要阻塞开发。
- 战斗规则逻辑在 `src/battle/core/`（纯 TypeScript），需要移植为 C# 放在 Unity 项目的 `Scripts/Core/` 下。**F 组写实化只动渲染层，不碰战斗逻辑。**
- 红军必胜与静止测试（玩家挂机也能胜利）不可破坏；15–20 人机同场 ≥ 30 FPS；无断肢、无喷血。
- 每次改动后 Unity 构建必须通过；涉及导航/阶段切换用 Playwright 补跑 e2e 测试。
- 对外文案避免使用"游戏"一词，统一用"应用/体验/战役模拟"。
