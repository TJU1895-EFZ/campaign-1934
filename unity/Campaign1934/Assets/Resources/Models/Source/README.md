# Soldier model provenance

The two soldier FBX files in the parent directory were generated locally with
[Ara 3D Gen](https://github.com/olatunde85/3d-gen) at commit
`0c3473d7d46a2badcdcd1dcfd4aeb0762eb04b20`.

- Generator source: MIT License (`3d-gen-LICENSE-MIT.txt`).
- MakeHuman system assets used by the generator: CC0
  (`MakeHuman-ASSETS-LICENSE.txt`).
- Generated soldier FBX files and project-specific settings are distributed
  under MIT (`MODEL-LICENSE-MIT.txt`). The CC0 source data permits this use.
- Exact reproducible character settings: `red.json` and `kmt.json`.
- No downloaded commercial or unlicensed soldier model is included.

The red model uses a grey-blue field uniform and cloth cap. The opposing model
uses a khaki/olive field uniform and helmet. The application adds the red
armband at runtime so it remains visible across animation and LOD variants.
